Projects completed for Oregon State University's CS 370: Introduction to Security, where important security concepts were introduced.

The projects are:

Bloom Filter, which required implementing a Bloom Filter to parse a large file, add items within the file to the filter, then parse another file and check for potential membership within the first file.

OTP, which required creating a OTP client that generates a QR code to add to Google Authenticator to make a 30-second TOTP, as well as a function for checking the current OTP.
